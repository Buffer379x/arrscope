# Scopearr 0.3.2

- Redesign library filters: a persistent, fixed-size search field and preset toolbar, media attributes on the left, metadata/status checkboxes on the right. Collapse only hides the detailed controls. Attribute dropdowns keep checkbox-based multiple selection.
- Replace operator dropdowns with green inclusion and red exclusion icons. Audio, HDR and language provide a labeled four-state operator menu. Changing an unchecked status filter's operator never activates its checkbox.
- Open Settings as a full page with section navigation for Services, Display and columns, Colors and tags, Filename recognition, and System. Keep the gear between theme and sign-out controls. Preserve library filters and pagination; warn before discarding unsaved edits.
- Compact tag color controls into a right-aligned group. Text color cycles through automatic, black and white using a single icon; reset asks for confirmation and restores background and text defaults.
- Reject equivalent preset filters per library, regardless of selected-value ordering, duplicate values, unused/default operators, pagination, sorting or preset name. Normalize language aliases and numeric ranges. Existing records remain untouched; server-side serialization also blocks concurrent duplicate creation.
- Add manual synchronization to service settings. Emby matching queues both enabled libraries with Emby enrichment using the existing read-only sync path. Saved connections are used; overlapping jobs remain blocked.
- Remove the audio mapping information icon from library rows. Audio data and detail views remain available through the file icon beside the title.
- Translate all new controls and messages into English, German, Spanish and Italian.

- Reserve additional memory headroom for SQLite backups and filename-rule reprocessing: cap the Go target at 64 MiB in a 256 MiB container and release reclaimable heap pages before those heavy operations.

## Upgrade

No database schema migration is required; schema 5 remains in use. Existing caches, presets, connections, recognition rules, colors and column layouts are retained. Update manually from Unraid after publication.

Images: `ghcr.io/buffer379x/scopearr:0.3.2` and `stable`, for `linux/amd64` and `linux/arm64`.

Full-cache recognition updates reuse a prepared update statement and retain unchanged indexed language associations. Their authenticated request budget is bounded at 180 seconds to accommodate large caches on slower hosts; ordinary HTTP query limits and the 256 MiB/no-swap stress limit remain unchanged. Tests verify language index changes, preservation and removal, cancellation and atomic rollback.

Historical release: Scopearr was renamed in 0.4.0. The versioned images are unchanged copies of the original binaries and retain their historical embedded branding.
