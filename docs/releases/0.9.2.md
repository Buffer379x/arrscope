# Scopearr 0.9.2

- Fix missing video enrichment from uniquely matched Emby and Jellyfin media sources: resolution, video codec and bit depth now fill gaps after filename and Arr metadata. File details show each provider's video dimensions and normalized codec.
- Recognize MPEG-4 Part 2 FourCC identifiers such as XVID and DX50 without inventing encoder names from H.264/HEVC streams. Preserve cropped/interlaced resolution information; nonstandard SD heights remain explicit.
- Supplement missing Channels only from an explicit layout of a single or uniquely default audio track. Never infer a speaker layout from channel count alone.
- Preserve media-server video metadata through cache rewrites and recognition-rule changes. Detect conflicting provider video values and avoid crossing alternate media versions.
- Simplify the matching widget to four mutually exclusive groups: Matched, Not found, Needs review and Not checked, each with accessible explanations. Detailed matching filters remain available and existing presets remain compatible.

After updating, run a regular library sync to fetch previously discarded video fields. Source, processing and unreported languages remain unknown unless supported by filename/Arr data; a media-server title match alone does not identify a physical file.

Images: ghcr.io/buffer379x/scopearr:0.9.2 and stable, for AMD64 and ARM64. Unraid updates remain user-triggered.
