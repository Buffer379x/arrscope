# Scopearr 0.7.2

- Replace the storage dropdown with previous/next area navigation and remember the selection in this browser. Match the collapsed Audio/Language card height, retain the donut and remove the footer explanation.
- Add optional per-service external custom-tag imports, with manual, five/fifteen/thirty-minute and library-sync checks. Local edits queue an immediate check; outbound Custom synchronization controls sending changes back.
- Reconcile remote snapshots with durable local intents before writing, preserve file-level Scopearr assignments and apply externally assigned Sonarr tags across series files. Failed reads retain the previous complete state; conflicts pause writes for review.
- Show an auto-tag gear with rule information, protect externally rule-controlled names/assignments/deletion in the UI and backend, and keep colors editable. Do not change external auto-tag rules. Remove the rule marker when its references disappear, retaining existing assignments.
- Centralize custom-tag management and color controls in Custom tags while sharing the existing Display color settings. Color changes use an explicit Save colors action; tag CRUD remains immediate.
- Add schema 12 with a consistent pre-migration backup for external definitions, snapshots and pending changes. Existing cache, presets, tag colors and credentials remain available.
