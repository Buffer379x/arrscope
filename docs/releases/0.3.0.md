# ArrScope 0.3.0

- Add a dedicated filename-recognition page in Settings → System with sortable rules, editing, enable/disable controls, defaults and a filename preview.
- Support case-insensitive tokens and Go RE2 regular expressions, priorities, direct recognition, missing-value fallbacks and explicit overrides. For example, an optional `UHDBD → 2160p` fallback fills missing resolution without replacing an explicit `1080p`.
- Save rules and reprocess cached filenames atomically, without contacting upstream services or scanning media. Preserve API provenance and verified Emby audio tracks. Existing custom rules survive restarts and updates.
- Show recognition-rule conflicts separately from filename/metadata disagreements, with different icons and independently configurable warning colors.
- Add filters for recognition conflicts and unsuccessful Emby matches, including detailed failure states. Keep metadata disagreement filtering separate.
- Consolidate audio languages and per-track codecs into one Audio column. Preserve codec and language filters and existing presets; migrate saved column layouts automatically.
- Move filename hover and file-detail actions to the icon before the title.
- Match the Dashboard heading size to the library headings and remove its subtitle.
- Add language distribution with clickable flags and temporary filters. Each movie or episode counts once per language; multilingual titles can occur in multiple groups.
- Translate the new interface into English, German, Spanish and Italian.
- Reduce paginated sort memory by sorting compact row IDs before loading media details. Reserve container memory for SQLite and page cache by clamping the Go memory target to half the detected container limit, including existing Unraid templates.

## Upgrade

This release upgrades SQLite to schema 5 and creates a consistent database backup before migration. Existing settings, presets and Emby enrichment are retained. Default rules reproduce the existing filename parser; the `UHDBD` fallback is an example you can add, rather than an automatically enabled inference. Rule edits also create a backup; the three most recent snapshots are retained.

To roll back to 0.2.3, stop the container and restore its matching pre-migration database backup or complete Appdata backup with the corresponding encryption key. An older image alone cannot open schema 5. See [operations](https://github.com/Buffer379x/arrscope/blob/main/docs/OPERATIONS.md).

After the release workflow completes, `ghcr.io/buffer379x/arrscope:0.3.0` and `stable` are available for amd64 and arm64. Install the update manually from Unraid's Docker page.
