# Scopearr 0.9.0

- Configure visibility and order of the six graphical dashboard widgets in Settings → Widgets: resolution, codec, source, audio, language and storage.
- Restore the default widget order and visibility with the existing reset control. Summary counters and metadata-quality cards remain unchanged.
- Set a shared number of entries per page for Movies and TV series in Settings → Display. The default is 100, with a supported range of 1–1000.
- Preserve widget settings and page size across restarts. Existing installations retain all six graphical widgets in their previous order.
- Apply the page size to matching-file and full-season views; keep CSV exports and bulk tag assignments independent of pagination.
- Translate the new settings into English, German, Spanish and Italian.

Images: `ghcr.io/buffer379x/scopearr:0.9.0` and `stable`, for AMD64 and ARM64. Unraid updates remain user-triggered.
