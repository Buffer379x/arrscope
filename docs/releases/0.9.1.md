# Scopearr 0.9.1

- Align the Language dashboard widget with the other graphical widgets.
- Rename the display settings card to List display icons.
- Right-align all state-filter operators and add short accessible explanations to every status and media-server matching filter.
- Move the general filter-logic help beside Media attributes and unify the matching-section heading size.
- Split Processing into its own sortable library column, with independent visibility and ordering. Existing layouts gain the column after Source when Source is visible; Source no longer includes processing tags.
- Use a constrained HH:MM text input for sync start times, avoiding overflowing native time controls on iPad.

Images: `ghcr.io/buffer379x/scopearr:0.9.1` and `stable`, for AMD64 and ARM64. Unraid updates remain user-triggered.
