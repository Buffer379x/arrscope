# Scopearr 0.6.0

- Add a saved interface-theme preference beside Interface language. **Default** retains the existing palette; **Nordic** and **Catppuccin** offer restrained blue and slate alternatives in both dark and light mode. Theme changes apply with Save settings. Layout, filters and custom media-tag colors remain independent.
- Simplify the library’s status filters: show Emby matching directly, remove the Unknown file size checkbox, and move Filter logic into an accessible question-mark tooltip beside Status and metadata quality. Existing saved filters remain compatible.
- Remove Languages from the Tag colors selector; language flags keep their compact presentation. Add a bundled Turkish flag and aliases, including `Turkish`, `Türkisch`, `Türkçe`, `tr` and `tur`. Unsupported languages retain the neutral icon; recognition rules do not download or generate flags.
- Improve primary-action text contrast in light mode.

Palette adaptations use [Nord](https://www.nordtheme.com/docs/colors-and-palettes/) and the blue/neutral colors of [Catppuccin Mocha and Latte](https://catppuccin.com/palette/); selected colors are adjusted for interface contrast. No external fonts, theme downloads or image requests are added.

## Upgrade

No database schema migration or media scan is required. Existing installations default to the original interface theme. Keep the current Appdata mount and credentials. Images: `ghcr.io/buffer379x/scopearr:0.6.0` and `stable`, for AMD64 and ARM64. Unraid updates remain user-triggered.
