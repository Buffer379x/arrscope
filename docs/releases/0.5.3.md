# Scopearr 0.5.3

- Add a read-only removal preview showing tag origin, affected movie/series counts, paginated titles and planned definition cleanup. Require explicit confirmation before applying removals; reject stale previews when relevant data changes.
- Record definition provenance separately from control and assignment ownership. Previously controlled values update automatically; new foreign assignments pause tag synchronization for review in Settings → System while file synchronization continues. Use targeted add/remove operations so concurrent foreign additions survive.
- Synchronize unknown values using stable English category prefixes, including `resolution-unknown`, `codec-unknown` and `audio-codec-unknown`. Keep translated Unknown labels in the interface. Series union known and missing episode values; empty custom selections do not generate an unknown tag.
- Replace the duplicate tag-handling dropdown with the confirmation popup. Active services expose an edit icon for that same popup. Restore radio inputs to normal dimensions.
- Add an editable UHD BluRay source override, preserving equivalent customized/disabled rules and leaving resolution independent. Use slash-separated standard rule names without changing IDs or customized names.
- Add a sortable Tag checkbox to filename rules. Informational values stay readable and filterable, while color choices track enabled tag-producing rules and evaluated data. Extend configurable tag presentation to bit depth, channels and audio language flags.
- Save recognition edits and checkbox changes atomically after their individual confirmation, without a redundant page Save action. Failed changes restore the last accepted state; saved previews use the current rules.
- Add per-file custom-tag editing through a tag icon in the Custom column. Preserve the current page and filters; keep bulk operations scoped to actual matches across all pages.
- Move settings Save actions beside each section heading and merge color controls into Display. Arrange service status cards side by side on desktop, stack them on mobile, and place cache backup alongside Version.
- Keep destructive buttons in their normal style and tint only the trash icon red. Translate new controls into English, German, Spanish and Italian.

## Upgrade

A consistent backup precedes SQLite schema 9 migration. Keep `scopearr.db`, the existing appdata mount and `secret.key`. Accounts, encrypted keys, settings, presets, cached Emby metadata and customized rules remain intact. Active outbound services reconcile after migration; older assignments with unrecorded ownership may need one initial review before removal. Newly enabled groups remain opt-in. No media scans are requested.

Read the [tag synchronization guide](https://github.com/Buffer379x/scopearr/blob/v0.5.3/docs/TAG-SYNC.md). Images: `ghcr.io/buffer379x/scopearr:0.5.3` and `stable`, for AMD64 and ARM64. Unraid updates remain user-triggered.
