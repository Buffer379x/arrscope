# Scopearr 0.4.0

- Rename the application, repository, documentation, container, Compose service and Unraid template to Scopearr.
- Add a configurable Custom column with alphabetically ordered, multi-valued tags. Manage tag names in Settings: create, rename or delete tags without changing their stable identity. Deleting a tag removes its assignments, related filename rules and preset references.
- Assign or remove tags for all actual filtered files across every page using the Custom tags checkbox dialog beside All columns and CSV. Mixed selections show a partial checkbox state; Apply commits the requested changes atomically. Extra season-context rows are excluded.
- Add Custom filtering with inclusion, exclusion, contains-all and does-not-contain-all operators. Custom tag colors and text colors reuse the existing color tables and show only tags currently in use.
- Filename-recognition rules can assign existing custom tags. Multiple matching tag rules are additive and are not metadata conflicts. Cached files are reprocessed atomically; manual additions remain intact. A manual removal of an automatic tag lasts until the next successful service sync. Manual assignments belong to the upstream file ID; removed or replaced files are classified again by filename rules.
- Extend CSV export with the same alphabetically ordered Custom tags used by the table. Translate the new controls into English, German, Spanish and Italian.

## Upgrade from 0.3.x

SQLite upgrades to schema 6 with an automatic backup. Existing accounts, settings, API keys, presets, recognition rules, media and Emby data are retained. Keep the existing `/data` mount and local encryption key. Scopearr creates a consistent `scopearr.db` copy of an existing `arrscope.db`, including committed WAL pages, and retains the old database for rollback. New names are used going forward; legacy environment variables, sessions, browser preferences and encrypted-key formats remain readable.

New installations use `ghcr.io/buffer379x/scopearr:stable`, the `scopearr` Compose service and `deploy/scopearr.xml`. The existing `ghcr.io/buffer379x/arrscope:stable` update channel points to the same approved image so current Unraid installations can receive this upgrade. Keep the existing appdata path when changing the repository/name in Unraid; do not create an empty appdata directory. Unraid updates remain manual.

For rollback, stop Scopearr and restore a complete pre-upgrade appdata backup together with the earlier image. Custom tags are not supported by earlier versions.

Images: `ghcr.io/buffer379x/scopearr:0.4.0` and `stable`, for `linux/amd64` and `linux/arm64`.
