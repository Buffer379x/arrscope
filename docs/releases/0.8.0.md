# Scopearr 0.8.0

- Add optional Jellyfin integration alongside Emby, with independent enabled states, URLs, encrypted keys and path mappings in one Media server settings card. Both can be active. Disabled providers disappear from file details and System; conflicting track inventories remain explicit rather than being merged.
- Rename matching views to Media server matching. Replace the matching dropdown with include/exclude checkboxes, combine selected states with OR and remove redundant unsuccessful-match and Unknown year controls. Existing unsuccessful-match presets also include conflicting media-server inventories.
- Add Technical outliers and Language outliers for TV seasons, based on strict season majorities. Include question-mark explanations, row/season highlighting, attribute details, multi-episode weighting, indexed filters, CSV flags and atomic recomputation after syncs, webhooks and rule edits.
- Place incoming external tags and outbound tag controls side by side on desktop, with a stacked mobile layout. Align the section headings.
- Clarify Shared storage group as deduplication identity, separate from editable display names.
- Use Quelle consistently for Source in the German interface; retain the other localized labels.
- Migrate to schema 14 with a consistent backup. Preserve existing Emby settings, presets, cached tracks, tag names and colors.
- Extend the 100,000-file container check to simultaneous Emby/Jellyfin enrichment under the unchanged 256 MiB memory limit without swap. Reuse identical normalized tracks to avoid unnecessary copies.

Images: `ghcr.io/buffer379x/scopearr:0.8.0` and `stable`, for AMD64 and ARM64. Unraid updates remain user-triggered.
