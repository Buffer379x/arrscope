# Scopearr 0.7.1

- Shorten dashboard widget headings to Language and Storage. Remove right-hand header counts/icons throughout the dashboard.
- Add an Audio codec distribution widget beside Language, with the same top-five expansion, colored tags, per-file counts and existing-filter drilldowns. Multiple codecs are counted once per file each, including incomplete audio in the Unknown filter.
- Let dashboard cards expand independently and increase the storage donut to use its card area. Keep the layout responsive.
- Match the compact Info layout reset button to the default-column reset controls.
- Move each service's connection test beside its service heading, clearly separating it from webhook setup.
- Add an accessible eye toggle inside the webhook password field so dedicated credentials can be revealed and copied, returning to hidden state when the credentials close.

- Replace summed storage with an individual-area selector. Explicit shared groups deduplicate paths, while overlapping Unraid shares are never added. Display decimal GB/TB and explain that used space includes other filesystem data. Existing selections and colors remain available. No Unraid integration is required.

Images: `ghcr.io/buffer379x/scopearr:0.7.1` and `stable`, for AMD64 and ARM64. Unraid updates remain user-triggered.
