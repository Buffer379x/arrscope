# Validation — 0.6.1

Validation used isolated local synthetic data on macOS/Apple Silicon. No production Unraid, Radarr, Sonarr or Emby access occurred.

- All 22 frontend tests, TypeScript, Vite and version checks passed. The 17 non-default palettes are tested in both modes for normal and muted text on every interface surface, primary actions and selected navigation at a minimum 4.5:1 contrast ratio. Original Default/Nordic/Catppuccin palettes are preserved. The backend accepts all 18 theme IDs and rejects unsupported values; persisted preferences survive server startup.
- Go race tests and vet passed. New recognition tests cover custom Ultra.HD tokens with and without explicit edge separators, all three modes, single-value conflicts, literal interior text, false positives and priority ordering. User and default rules share the same ordering; there is no built-in precedence branch. Fallback respects existing direct results and override resolves conflicting direct source results.
- Browser checks saved each of the 15 additional palettes in dark and light mode. Heading position and card width stayed constant across all 30 combinations, with no desktop overflow. The rule dialog's Enabled and Tag color checkboxes are aligned beside each other on desktop and at 390 CSS pixels. A newly created synthetic rule with Tag color disabled retained that flag after reload and reopening. Only agent-created QA rules were removed afterwards; existing demo rules/preferences were retained.
- Browser reproduction of Movie.Ultra.HD.BluRay.mkv used a Source token .Ultra.HD., result UHD and priority 95. Explicit override returned UHD with the custom rule's provenance; Only if missing returned BluRay with the direct default rule's provenance. Mode and token hints have separate accessible descriptions, preserving concise field labels. No rule modes were automatically rewritten.
- The strict 256 MiB/no-swap, read-only/non-root fixture completed 100,000 files with two Emby tracks per file. Sampled process RSS peak was 208.09 MiB, settled RSS 37.85 MiB, HTTP filter p95 27.923 ms, cached Dashboard p95 0.935 ms, recognition reprocessing 20393.028 ms, rewrite peak 39.12 MiB. Cached Emby tracks survived reprocessing and zero upstream requests were made with outbound tag sync disabled. No OOM occurred. Measurements are environment-specific; cgroup peak includes reclaimable filesystem cache.

Language recognition and flag data were inspected, not expanded: known language aliases resolve locally, but arbitrary country markers do not establish an audio language. No schema migration is required. Existing cached token results update on a rule save or successful file sync. CI and release workflows repeat full security, runtime, multi-architecture and performance checks before stable promotion. No gates were relaxed. Screenshots were inspected inline; screenshot-file export remains unavailable in the browser runtime.
