# Scopearr 0.5.4

- Rename filename recognition to **Tag rules** and its presentation checkbox to **Tag color**. All recognized values remain available to filters and outbound synchronization independently of that checkbox.
- Keep language flags at their original fixed dimensions without surrounding tag badges. Unknown/neutral language icons have no frame. Optional colors change only the existing thin edge of known flags and add no padding; unknown-language colors are not offered. Color choices exclude inactive rules even when an old color override is stored; overrides are retained for later reactivation.
- Batch Enabled/Tag color checkbox edits as a draft, applied once by **Save settings** beside the section heading. Confirmed rule creation, editing, deletion and reset still commit immediately, without implicitly committing other pending checkbox edits. Failed saves preserve the draft. Preview evaluates the current draft without touching the media cache.
- Serialize cache reprocessing with file/tag synchronization and begin SQLite write transactions immediately, avoiding read-to-write snapshot upgrade collisions. Reserve extra non-Go memory headroom during large cache rewrites and apply an advisory SQLite heap target; retain the strict container memory limits.
- Broaden the existing UHD BluRay default into a standalone UHD-token source override. Recognize `UHD`, `UHD.JAP.BluRay` and `UHD.US.BluRay` as Source UHD. Preserve rule IDs, customized names, priorities, enable/color flags and user-modified patterns. Explicit WEB-DL, WEBRip, HDTV and DVD tokens are excluded from this override so a UHD quality marker does not replace a different known source. Resolution remains independent; UHDBD keeps its own default.
- Remove the separate tag-handling edit icon. Existing assignment decisions and the destructive removal preview remain part of saving tag-sync configuration changes.
- Remove empty dashes from the Custom column, leaving its per-file tag editor available.
- Remove the swap-limit request from the Unraid template while retaining the 256 MiB RAM limit and existing isolation. The warning is host-capability-related, not an application failure. Compose and automated checks retain strict 256 MiB/no-swap limits.

## Upgrade

A consistent backup precedes schema 10 migration. Keep the current Appdata mount, `scopearr.db` and `secret.key`. Customized patterns are preserved; only the untouched UHD BluRay pattern is broadened and its cached results reprocessed. No media scans are requested.

Unraid stores Extra Parameters separately from the image. Updating the image alone does not replace them. On a host reporting unsupported swap accounting, edit the container and remove only `--memory-swap=256m`, retaining `--memory=256m` and the other parameters. Hosts supporting swap accounting may keep the stricter flag. See [Unraid instructions](https://github.com/Buffer379x/scopearr/blob/v0.5.4/docs/UNRAID.md) and [Docker resource constraints](https://docs.docker.com/engine/containers/resource_constraints/).

Images: `ghcr.io/buffer379x/scopearr:0.5.4` and `stable`, for AMD64 and ARM64. Unraid updates remain user-triggered.
