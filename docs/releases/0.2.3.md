## Updating

Update the ArrScope container manually in Unraid once `stable` has been promoted. Keep the existing `/data` volume. No database migration is required; connections, cached libraries, presets and appearance preferences are preserved. Browser favicons use a new cache key. An existing Unraid template may require refreshing its icon URL or clearing the browser icon cache to display the new artwork.
