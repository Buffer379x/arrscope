## Upgrade

A consistent backup precedes schema-8 migration. Accounts, credentials, settings, presets, cached Emby metadata and existing recognition rules are retained. Existing 0.5.1 synchronization continues in its replacement mode; newly enabled groups require an explicit choice, and all groups remain off for new installations. Adding the UHDBD default reprocesses the cache atomically without media scans.

Definition cleanup operates on affected, previously observed or recognized labels; it does not indiscriminately delete unrelated unused tags. A shared label represents one upstream tag even when multiple Scopearr groups use it. Cleanup requires an enabled, reachable service. Complete deletion on the original address before moving to another server; URL fingerprints prevent applying old resource IDs to a new endpoint.
