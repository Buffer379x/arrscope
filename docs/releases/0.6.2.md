# Scopearr 0.6.2

- Bundle 7,994 ISO language records covering ISO 639-1 two-letter codes, ISO 639-2 bibliographic/terminological aliases and ISO 639-3 identifiers. Metadata codes resolve consistently across the server, filters, audio tracks, Dashboard and localized language labels. Existing known canonical values stay compatible. Registered codes take precedence over colliding short language names; ambiguous canonical names retain their identifier internally.
- Add locally bundled flags for 6,576 living-language records, using curated mappings and pinned CLDR likely-territory defaults, including Chinese, Korean, Czech, Greek and Ukrainian with selected regional flags. ISO standards identify languages rather than countries; unmapped, ancient, constructed and collective/special languages retain the neutral icon with a readable name. No runtime downloads or filename-country guessing are introduced. See [language data and attribution](https://github.com/Buffer379x/scopearr/blob/v0.6.2/docs/LANGUAGES.md).
- Save custom tags immediately when Add is clicked or a deletion is confirmed. Remove the redundant section Save button. Name edits commit on Enter or blur; atomic revision checks and cleanup of assignments/rules remain in place. Failed writes preserve stored data.
- Confirm before dismissing an edited recognition-rule dialog, including backdrop, Escape, Close and Cancel. Cancelling the confirmation retains the draft. An untouched dialog can close directly.
- Show a spinner and explicit cache-update status while saving a rule; disable duplicate submits and dismissal until the operation completes. Failed saves keep the dialog and inputs available. Progress is indeterminate because no reliable completion percentage is available.

## Upgrade

A consistent backup precedes SQLite schema 11 migration, which reprocesses existing cached API/Emby language evidence locally without media scans or upstream requests. Existing rules, custom tags, presets, credentials and settings are retained. Keep the current Appdata mount and local key; rollback requires the matching database backup.

Language data uses a pinned Unicode CLDR mirror of SIL's 2026-07-15 ISO 639-3 snapshot and its Library of Congress ISO 639-2 table. Unicode and flag-icons licenses are included. Images: `ghcr.io/buffer379x/scopearr:0.6.2` and `stable`, for AMD64 and ARM64. Unraid updates remain user-triggered.
