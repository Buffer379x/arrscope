# Scopearr 0.9.4

A responsive-layout follow-up to 0.9.3.

- Constrain settings grid tracks and cards to the available width. Wide tag color tables now scroll inside their own box on phones instead of widening the entire page.
- Retain all 0.9.3 improvements: complete known audio channel summaries, a codec beside each track's language, regular frames for API-only codecs, and saved per-tag Display checkboxes.

No metadata, filter, synchronization or database behavior changes. After updating from 0.9.2 or earlier, run a full library sync to refresh channel summaries.
