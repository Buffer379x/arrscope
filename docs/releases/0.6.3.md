# Scopearr 0.6.3

- Add a separate Info column containing the service link, file details and both existing warning indicators. The link opens the Radarr movie or Sonarr series in a new tab, using the configured base address (including URL subpaths) and the API UI slug. Existing cached entries resolve missing slugs on demand through an authenticated, GET-only server request; API keys never appear in browser links.
- Add Display → List display controls for persistent icon visibility and left-to-right order, shared by both libraries. Warnings appear only when applicable and retain their configured colors. Hidden warnings remain available through filters and file details.
- Include Info in each library's column visibility and ordering controls. Existing installations gain the column before their existing columns, while preserving the relative order and visibility of all other columns. Info contains actions and therefore has no data-sort button or CSV field.
- Translate the new controls into English, German, Spanish and Italian.

## Upgrade

No SQLite schema migration is required. A consistent backup precedes the one-time additive settings upgrade. Existing cached data, settings, rules, presets and custom tags are retained. Rollback to an older version should restore that matching pre-upgrade backup because older versions do not accept the new Info column setting. Catalog slugs are captured on subsequent successful synchronizations; older cache rows remain usable via the read-only link resolver. No media scans or upstream writes are added.
