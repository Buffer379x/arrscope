# Language metadata and flags

Bundled language records cover ISO 639-1 two-letter codes, ISO 639-2 bibliographic/terminological aliases and ISO 639-3 identifiers. The shared registry contains 7994 records and is used by both server and interface. Existing canonical language values remain compatible; metadata codes are normalized before filtering, statistics and audio-track presentation. Filename countries are not automatically interpreted as audio languages.

Data source: [SIL](https://iso639-3.sil.org/code_tables/download_tables) ISO 639-3 snapshot 20260715, maintained in [Unicode CLDR](https://github.com/unicode-org/cldr/tree/a3ad818e51ea5ccc35e271ad86791b1166df5e36/tools/cldr-code/src/main/resources/org/unicode/cldr/util/data), plus its Library of Congress ISO 639-2 table and English names. Direct registration-authority downloads were unavailable, so the pinned Unicode mirror was used. Registry SHA-256: `b9c9906fbd5a769144db3d5df91464cb697254cd3ceb2ddb4213b3e28769dcdd`. Unicode data license is included under internal/langdata.

ISO language standards do not assign national flags. Scopearr retains curated mappings for common media languages and uses pinned CLDR likely-territory defaults for other living languages where a bundled flag exists. These are display conventions, not assertions of nationality or release location. Ancient, constructed, collective/special and otherwise unmapped languages show the neutral language symbol with their correct name. Flag assets are bundled from [flag-icons 7.3.2](https://github.com/lipis/flag-icons/tree/v7.3.2), under the included MIT license. No runtime downloads are required. Existing eleven inline SVG flags retain their original dimensions.

Language labels use the active interface locale through Intl.DisplayNames when supported, with the registry's English reference name as fallback. The original stored/filter values of the known languages remain unchanged. Regional metadata tags resolve through their language subtag; a flag is a language presentation convention and does not assert the release country or speaker nationality. Unknown codes remain visible rather than being guessed. `und` remains Unknown.

Registered codes take precedence over coincidentally identical language names. Canonical names that collide with another code include their ISO identifier internally (for example Ko (fuj)), preserving stable reprocessing and filter identity.
