# ArrScope 0.2.0

- Add English, German, Spanish and Italian throughout the interface, including login, settings, filter labels, tooltips, API errors and CSV headers.
- Save interface language per browser and automatically discover additional JSON translation catalogs. English is the fallback. Media names and stored filter values remain unchanged.
- Open temporary library filters by clicking dashboard distribution tags. Existing filters and presets are preserved; the combined dashboard scope offers a movie/TV selector.
- Replace audio language text with local SVG flag icons and accessible translated tooltips. Audio track language and codec stay associated. Unmapped languages use a neutral language icon.
- Add a root VERSION file, consistent application/container/package versions, release notes and CI checks that require a new version for changes after a release.
- Publish repository documentation and release information in English.

## Updating

Use Unraid’s normal update action for the ArrScope container after this release is promoted to `stable`. Keep the existing `/data` volume. This release requires no database migration; library data, saved presets, connections and API keys are retained. Interface language is a browser preference.
