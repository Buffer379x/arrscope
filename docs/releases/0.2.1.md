# ArrScope 0.2.1

- Move application version and connection status out of the header into Settings → System info. This section also shows cached service sync status, distinguishes disabled services and errors, and avoids implying a live connection to upstream services.
- Rename the main navigation to Movies and Series, translated in all four interface languages.
- Remove excessive transparent padding around the Docker icon and favicons while preserving the ArrScope logo.
- Derive darker borders and dashboard hover/focus outlines from custom tag colors instead of using the text color. Readable black/white text contrast is retained.
- Refresh the English GitHub screenshot using BluRay, DVD and UHD sources in isolated screenshot fixtures. Library parsing and real data remain unchanged.

## Updating

Update the ArrScope container manually in Unraid after `stable` is promoted. Keep the existing `/data` volume. No database migration is required. Cached data, connections, presets and appearance preferences are preserved. Browser favicons use a new cache key.
