# ArrScope 0.3.3

- Present tag colors and warning colors in bordered tables consistent with filename recognition. Keep column headings inside the table, previews inset on the left, and compact color, text-color and reset controls aligned on the right. Text-color and reset buttons have matching visible borders.
- Standardize single-select dropdowns to the same 42-pixel control height and padding as filter inputs. Remove the smaller preset-dropdown exception; selection behavior is unchanged.
- Remove the redundant Close button and divider from the settings footer. Save remains available, and navigation still warns before discarding unsaved changes.
- Keep the filename-preview result table visible before the first preview. Place a wider filename input above the table on the left; stack input and action on narrow screens.

## Upgrade

No database schema migration is required; schema 5 remains in use. Cached media, presets, connections, recognition rules, colors and column layouts are retained. Update manually in Unraid.
