# Scopearr 0.9.3

- The Channels column now falls back to every known audio layout from a verified Emby/Jellyfin file match. Multiple or missing default-track flags no longer turn known channels into Unknown. Distinct layouts appear as separate tags; reported channel counts without a layout stay counts instead of implying a speaker/LFE arrangement.
- Audio rows continue to show the codec next to each track's language, including when several languages use the same codec. Filename and Arr metadata retain their established priority.
- API-only codecs such as vp9 receive the normal tag frame; explicit information-only rules remain respected.
- Settings → Display → Tag colors has a saved Display checkbox between Count and Color. Disable a value to hide it from library cells and filter choices. Statistics, assignment counts, file details, exports, tag sync and saved filter predicates keep the underlying data.
- Reviewed the reported episode matches against the current cache. Both are matched and the Not found filter returns no TV files; exact filename/byte-size identity checks remain unchanged.
- Multiple video streams without a unique default remain ambiguous.

After updating, run a full Radarr and Sonarr sync to refresh cached channel summaries. All display checkboxes start enabled. No media scans, probing or media-directory mounts are introduced.
