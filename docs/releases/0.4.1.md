# Scopearr 0.4.1

- Replace dismissible notification banners with bottom-right toasts throughout the interface. Success messages last five seconds; warnings and errors last eight seconds. Hover or keyboard focus pauses dismissal. Input validation stays next to its field.
- Make settings edits explicit: language, display, colors, custom tags and filename rules apply only after Save. Leaving a section with pending edits prompts before discarding them. Login language selection remains immediate; connection tests, synchronization, backups and password changes are explicit actions.
- Save custom-tag administration drafts in one SQLite transaction, including renames, additions, deletions and cleanup of assignments, recognition rules, preset references and colors. Reject duplicate names and stale snapshots without partially applying changes.
- Unify settings cards with closed borders, consistent backgrounds and spacing. Give every settings section a distinct heading and description. Shorten navigation labels to Display and Colors; remove the filename-recognition back button.
- Fix Add rule on ordinary HTTP/LAN addresses by generating rule identifiers with getRandomValues rather than the secure-context-only randomUUID API. New rules remain drafts until Save; saving reprocesses the cached files without upstream calls.
- Move manual Radarr/Sonarr synchronization and Emby matching to their System cards. Running syncs show an indeterminate activity bar; no inaccurate percentage is displayed. Remove the sync footer from Movies and TV series.
- Show the five most frequent entries in each Dashboard distribution widget, expandable with More/Less. Keep totals and percentages based on the full library. Display languages in a single column and remove their explanatory paragraph. Move the Distribution scope switch directly above the charts, below the metadata-quality cards.
- Reclaim discarded Arr catalog and Emby matching buffers between large sync phases, release consumed snapshots before the next service, and bound SQLite page caches to 1 MiB per connection. Keep temporary tables on disk and preserve the 256 MiB/no-swap release gate.
- Translate all new controls into English, German, Spanish and Italian.

## Upgrade

No database schema migration. Keep the existing appdata mount and encryption key. Existing accounts, service credentials, custom tags, recognition rules, presets and cached media are retained. Interface language remains a browser preference, applied when saving Display settings.
