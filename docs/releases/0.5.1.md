# Scopearr 0.5.1

- Add optional outbound tag synchronization for Radarr movies and Sonarr series. Select resolution, codec, source/processing, HDR, bit depth, audio codec, channels, language and custom tags independently for each service. All groups are disabled by default.
- Treat enabled synchronization as authoritative: replace each movie/series tag assignment with the selected, currently recognized values, including removal of pre-existing assignments. Sonarr receives the union of all episode-file values. Reuse existing tag definitions and preserve global definitions when removing assignments.
- Reconcile tags after successful file synchronization and after relevant custom-tag/rule changes. Persist pending work across restarts, verify update responses, and retry failures without invalidating the last successful file snapshot. Never apply cached IDs to a different service URL.
- Expose tag synchronization activity and errors in System settings. Normalize outgoing labels to lowercase letters, digits and hyphens; labels do not depend on interface language.
- Add editable audio-comparison expressions to recognition rules. Default DTS, DTS-HD and DTS-HD MA rules tolerate differences within this family while preserving precise displayed track codecs. Clear the comparison expression to restore strict comparison.
- Exclude subtitle-qualified language tokens such as German.Subbed from default audio-language recognition. Upgrade only untouched defaults, retaining customized rules.
- Add recognition-rule search beside Add and the restore icon. Search all table columns, show the total rule count below the table, and retain the full rule set when saving filtered views.
- Replace filter/default-reset text actions with accessible revert icons. Remove the Custom filters preset entry and disable the All files selector when no presets exist for the current library.
- Align settings headings and custom-tag spacing; stretch the filename-preview input to fill the available row. Remove the Emby matching widget's expansion button and help text, showing every status directly.
- Translate the new interface controls into English, German, Spanish and Italian.

## Upgrade

SQLite schema 7 adds a durable tag-reconciliation ledger. Migration creates a consistent backup and preserves accounts, credentials, presets, custom tags and customized recognition rules. Updated default rules reprocess the existing cache without scans. Outbound synchronization remains disabled after upgrading until explicitly selected and saved.

Review [tag synchronization](../TAG-SYNC.md) before enabling it: existing upstream assignments are replaced. Disabling all groups clears assignments previously managed by Scopearr on the same service URL after successful reconciliation; global tag definitions remain available. Other upstream automation may subsequently reapply tags.

Images: `ghcr.io/buffer379x/scopearr:0.5.1` and `stable`, for `linux/amd64` and `linux/arm64`. The legacy `ghcr.io/buffer379x/arrscope:stable` channel receives the same approved image. Unraid updates remain manual.
