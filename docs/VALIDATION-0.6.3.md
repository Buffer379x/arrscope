# Validation — 0.6.3

Validation used isolated synthetic libraries on macOS/Apple Silicon. No production Unraid, Radarr, Sonarr or Emby access occurred.

- All 27 frontend tests, TypeScript, Vite, version consistency, Go race tests and vet passed. New tests cover API UI slug capture (including a TMDB ID distinct from the internal movie ID), preservation through local cache reprocessing, authenticated legacy resolution, GET-only endpoint restrictions, uncached ID rejection, URL subpaths and unsafe URL/slug rejection.
- Additive layout migration preserves the existing column order/visibility, adds Info, creates a consistent backup once and preserves encrypted credentials. Saved icon order, all-disabled icon selections and a hidden Info column survive reload; invalid action selections/orders are rejected.
- Browser checks opened synthetic Radarr and Sonarr targets in separate tabs. A movie missing its cached slug used the backend resolver; a series with a cached slug opened directly. Neither URL contained an API key. The source tab remained open.
- Browser checks saved Details → Link order, moved Info behind Title and hid the metadata icon. Reload retained the order and hidden warning. The metadata filter still returned the affected movie, and the file-details dialog opened correctly. Two synthetic filename rules produced both warning types; the requested icon order and both configured warning colors were retained.
- All four icons measured 29 × 29 CSS pixels in the dark and light desktop views. At 390 CSS pixels, the Display page had no horizontal body overflow and the new box fit the viewport. Hiding Info removed the column; All columns restored it in the saved position.
- The unchanged strict read-only/non-root 256 MiB/no-swap fixture passed 100,000 files with two Emby tracks per file and no OOM. Sampled process RSS peak: 221.71 MiB; post-query RSS: 48.16 MiB; HTTP filter p95: 24.784 ms; cached Dashboard p95: 0.965 ms; recognition rewrite sampled RSS peak: 47.7 MiB. Cached Emby metadata survived reprocessing and no upstream requests were made during rule reprocessing with outbound tags disabled. Measurements are environment-specific; cgroup peaks include filesystem cache.

SQLite remains at schema 11. The new optional titleSlug field is stored in file JSON, avoiding another cache-table rewrite. Normal list rendering does not contact upstream services. Screenshots were inspected inline; screenshot-file export remains unavailable in the browser runtime. CI and release repeat full security, runtime, architecture and performance checks before stable promotion. No gates were relaxed. See [entry link behavior and official sources](ENTRY-LINKS.md).
