# Scopearr 0.9.5

- Restore rule-controlled codec frames. API-only codecs, including vp9, remain plain text until an enabled tag-color recognition rule declares them.
- Align the Channels column with the Audio column, one row per verified track. Duplicate layouts remain visible; an unknown track never inherits another track’s channels. Filtering and tag synchronization retain their aggregate channel semantics.
- Add a chain-link/play icon for media-server entries in the Info column, directly after the Radarr/Sonarr link by default. A single enabled provider opens directly in a new tab; multiple enabled providers use a picker. Movies open the matched movie and episodes open their parent series. Missing identities are disabled, inactive providers are omitted, and existing icon visibility/order preferences remain configurable.

Run a full library sync after updating to populate media-server link identities in previously cached rows. No new media scans or playback requests are issued. Unraid updates remain manual through the stable image channel.
