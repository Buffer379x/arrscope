# Scopearr 0.7.3

- Put library synchronization actions beside the Radarr/Sonarr headings in System, outside the external-tag check block. Group incoming and outgoing tag controls in one consistent full-width section.
- Retain recognized tag/color entries when filename rules are removed. Add assignment counts and confirmed deletion actions; linked entries cannot be deleted. Unused entries remain available until explicitly removed. New recognized matches can restore a previously removed presentation entry.
- Add persistent local display names for ordinary and automatic external custom tags. Display names are used in lists, filters and CSV while canonical upstream labels and IDs remain unchanged. Automatic-rule assignments and deletion stay protected; display names and colors remain editable.
- Add assignment counts and deletion guards to Custom tags. Existing definitions and colors survive removal of external references, and returning external assignments restore their management indicators.
- Add editable names for every selected storage path, shared or independent. Names do not change shared-group identity or capacity calculations. Legacy selections default to their original path.
- Open Movies and TV series with collapsed filters, retaining the search field and selected criteria.
- Keep wall-clock scheduling anchored across the entire day: hourly at 20:00 also schedules 17:00 and 18:00 earlier that day. Add regression coverage for this behavior.
- Migrate to schema 13 with a consistent pre-migration backup for retained presentation tags and local display names.

Images: `ghcr.io/buffer379x/scopearr:0.7.3` and `stable`, for AMD64 and ARM64. Unraid updates remain user-triggered.
