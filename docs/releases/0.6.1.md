# Scopearr 0.6.1

- Expand the saved interface-theme selector to **18 choices**: Default, Nordic, Catppuccin, Graphite, Slate, Ocean, Atlantic, Forest, Sage, Sandstone, Copper, Coffee, Midnight, Ink, Steel, Mist, Linen and Charcoal.
- Each additional palette provides restrained neutral surfaces and blue, green, warm or grayscale accents in both dark and light mode. Theme selection still applies with Save settings; layout and media-tag colors remain unchanged.
- Validate all added palettes for readable normal text, muted text, primary actions and selected navigation. The server accepts exactly the same theme choices as the interface.

- Add **Tag color** beside **Enabled** in the rule creation/editing dialog. Its initial state reflects the rule's current setting; both flags are saved with the confirmed rule. Table checkbox drafts still require Save settings.

- Fix literal tokens with explicit edge separators: `.Ultra.HD.` now matches `Movie.Ultra.HD.BluRay.mkv` without requiring duplicated dots. Preserve literal interior text, priorities and modes; user rules do not have lower precedence than defaults. Add rule-dialog guidance explaining that priority applies within a mode and fallback never replaces a known result. Use Source → UHD with Explicit override for this example. Saved definitions are preserved; cached results refresh on a rule save or successful file sync.

## Language flags

Flags are locally bundled SVGs for eleven known language mappings, not a downloaded collection of every country flag. Known language names and ISO language aliases such as `de`, `deu`, `ger`, `en` and `eng` resolve to the corresponding icon. Turkish support was added in 0.6.0. An arbitrary country token in a filename is not assumed to identify an audio track: metadata or an explicit recognition rule must supply the language value. Unsupported values retain the neutral language icon. This release does not change recognition rules or rewrite saved language filters.

## Upgrade

No database migration is required. Existing theme selections are preserved. Images: `ghcr.io/buffer379x/scopearr:0.6.1` and `stable`, for AMD64 and ARM64. Updates in Unraid remain user-triggered.
