# Scopearr 0.7.0

- Sort the uppercase Info column by the number of visible icons, then title, in both libraries. CSV follows the selected order. Add a reset control for the default Link, File details, Metadata disagreement and Recognition conflict icon layout.
- Show a cached, automatic GitHub release check in System, without an update button. Checks run every six hours; failures preserve the last successful result.
- Add optional clock-anchored service schedules with an explicit IANA timezone. Existing elapsed-time intervals remain unchanged when no start time is configured.
- Add Settings → Widgets: select Radarr/Sonarr disk-space paths, assign shared storage groups, and customize Used/Free chart colors. Dashboard capacity charts follow Entire library, Movies and TV series; a shared group is counted once rather than twice.
- Add disabled-by-default, authenticated Radarr/Sonarr webhooks for imports, upgrades, file deletions and renames. Persist and coalesce affected media jobs, reconcile via targeted GET requests, and atomically replace only affected cache records. Retries preserve existing data. Optional outbound tags use the affected movie/series rather than reloading its entire catalog.
- Remove library subtitles, use a tag icon with Set tag, and improve language-widget and service tag-control spacing. Translate the new controls into all four interface languages.

## Setup and upgrade

No SQLite schema migration is required. Existing files, settings, rules, presets and custom tags are retained. The new storage selections start empty and webhooks are off. Select paths explicitly in Widgets; use the same group name only for paths on the same underlying storage. Disk-space APIs report container-visible filesystem capacities, which may differ from Unraid share disk restrictions. See [widgets and schedules](https://github.com/Buffer379x/scopearr/blob/v0.7.0/docs/WIDGETS.md).

To enable realtime updates, save Enable webhook for each service, reveal its dedicated connection credentials and configure the corresponding Radarr/Sonarr Webhook connection. See [webhook setup](https://github.com/Buffer379x/scopearr/blob/v0.7.0/docs/WEBHOOKS.md). Existing Emby tracks are preserved for unchanged files; newly imported or replaced files receive Emby track enrichment on the next full sync. Scheduled full synchronizations remain the recovery mechanism for missed events.

Images: `ghcr.io/buffer379x/scopearr:0.7.0` and `stable`, for AMD64 and ARM64. Unraid updates remain user-triggered.
