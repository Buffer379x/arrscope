# ArrScope 0.3.1

- Align Dashboard, Movies and TV series heading positions, line heights and the start of the first card on desktop and mobile. Reserve scrollbar space to prevent horizontal shifts between short and long pages.
- Remove the Dashboard footer explanation.
- Apply Dashboard tag and language clicks directly to the existing library filter controls and expand the filter panel. Each click replaces that library's current query with the selected attribute, so unrelated filters cannot hide matching files. The other library's filters remain independent. For the combined Dashboard scope, use the currently selected library; select Movies or TV series in the Dashboard to choose explicitly.
- Remove the separate temporary-filter banner and its controls. Dashboard selections remain in memory until changed or the page is reloaded; saved presets are changed only by explicitly saving a preset.
- Add black, white and automatic text-color choices per recognized tag in Settings. Save text colors independently from backgrounds, retain the darker border and hover outline, and preview the selection immediately. Existing installations keep their previous automatic text colors. Reset restores both defaults.
- Translate the new controls into English, German, Spanish and Italian.

## Upgrade

No database schema migration is required; schema 5 remains in use. Existing connections, recognition rules, presets, cached files, column layouts and tag background colors are retained. Update ArrScope manually from Unraid's Docker page after the release workflow completes.

Images: `ghcr.io/buffer379x/arrscope:0.3.1` and `stable`, for `linux/amd64` and `linux/arm64`.
