# Validation — 0.6.0

Tests used isolated local synthetic data on macOS/Apple Silicon. No production Unraid, Radarr, Sonarr or Emby access occurred.

- Go race tests and vet passed. Settings tests cover upgrade defaults, the palette allowlist, HTTP persistence/rejection and reloading a stored selection on server startup.
- All 21 frontend tests passed, along with TypeScript, Vite and the version consistency check. Palette tests enforce at least 4.5:1 contrast for normal/muted text on all three interface surfaces, primary action text and selected navigation in both new palettes. Switching palettes/modes and returning to Default removes old inline tokens. Translation catalogs have matching keys and placeholders in all four languages.
- Browser checks inspected Default, Nordic and Catppuccin in dark/light mode. An unsaved selection leaves the outer interface unchanged; Save applies the preference, and a container restart retains it. The cards share equal desktop widths and stack at an actual 390-CSS-pixel viewport without document overflow. The previous duplicated language caption is suppressed only inside the preferences card; its select retains an accessible label. Custom tag colors are independent of palette tokens.
- Emby matching is directly visible in the expanded filter panel. Unknown file size and both disclosures are absent. The help icon aligns with the status operator buttons; click/focus/tap opens the localized tooltip and Escape dismisses it. Its bounds stay within the mobile viewport. The title search remains 42 pixels high when the panel is collapsed.
- Language is absent from the Tag colors dropdown. Turkish names and ISO aliases resolve to the bundled flag; unsupported languages retain the neutral symbol. No external theme or flag downloads are added.
- The unchanged strict 256 MiB/no-swap read-only/non-root container fixture completed 100,000 files with two Emby audio tracks per file: sampled process RSS peak 209.60 MiB, settled RSS 37.50 MiB, HTTP filter p95 28.141 ms, cold Dashboard 1306.697 ms, cached Dashboard p95 1.238 ms, recognition reprocessing 20942.109 ms. Recognition retained Emby tracks and made zero upstream requests with outbound sync disabled; its sampled peak was 40.22 MiB. No OOM occurred. Measurements are environment-specific; cgroup peak includes reclaimable filesystem cache.

Browser screenshots were inspected inline. Screenshot-file export remains unavailable in the browser runtime; no screenshot files or fabricated proof were included. No schema migration is needed. Pull-request and release workflows repeat security, performance, runtime and multi-architecture checks before stable promotion; no gates were relaxed.
